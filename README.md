## Qué es este proyecto

Sitio web estático basado en la plantilla **Craftivo** (BootstrapMade), usada como producto de prueba para el despliegue.

| Elemento | Elección |
|----------|----------|
| Plantilla | [Craftivo](https://bootstrapmade.com/craftivo-bootstrap-portfolio-template/) (HTML/CSS/JS, Bootstrap) |
| Hosting | **GitHub Pages** (gratuito) |
| Dominio | `https://juancho946.github.io/craftivo-landing-sena/` (subdominio gratuito de GitHub) |
| Control de versiones | **GitHub** |
